📊 FLUJOS DE TRABAJO IMPLEMENTADOS
════════════════════════════════════════════════════════════════════════════════

Flujo 1: Retiro de Pallets de Producción
─────────────────────────────────────────────────────────────────────────────
1. Planta crea ticket "Retiro pallets producción"
2. CD asigna rampla disponible
3. Rampla viaja a Planta (en tránsito)
4. Planta confirma llegada (acepta/rechaza/observa)
5. Planta inicia carga
6. Planta finaliza carga → Alerta a CD
7. CD asigna muelle
8. CD inicia descarga
9. CD finaliza descarga → Libera recursos

Flujo 2: Solicitud de Pallets Vacíos
─────────────────────────────────────────────────────────────────────────────
1. Planta crea ticket "Solicitar Pallets vacíos"
2. Galpón aprueba solicitud
3. CD asigna rampla
4. Rampla viaja a Galpón
5. Galpón confirma llegada
6. Galpón carga pallets vacíos
7. Rampla viaja a Planta
8. Planta confirma llegada
9. CD gestiona retorno y libera recursos

Flujos de Excepción:
─────────────────────────────────────────────────────────────────────────────
• Planta rechaza rampla → Libera rampla, notifica CD
• CD rechaza carga → Estado "Rechazada", motivos predefinidos
• CD cancela ticket en tránsito → Libera recursos, notifica
