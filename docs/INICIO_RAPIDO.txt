⚙️ PASO 2: CONFIGURAR SUPABASE (20 minutos)
════════════════════════════════════════════════════════════════════════════════

Las credenciales actuales son PERSONALES y deben ser reemplazadas.

2.1. Crear Proyecto de Supabase
─────────────────────────────────────────────────────────────────────────────
   1. Ve a https://supabase.com/
   2. Crea cuenta con email corporativo
   3. Crea nuevo proyecto:
      Nombre: ramplas-production (o el que prefieras)
      Región: Más cercana a tu ubicación
      Contraseña BD: Usa una segura y guárdala

2.2. Obtener Credenciales
─────────────────────────────────────────────────────────────────────────────
   1. Ve a Project Settings → API
   2. Copia:
      • Project URL → Lo necesitarás para environment.ts
      • anon/public key → Lo necesitarás para environment.ts

2.3. Crear la Base de Datos
─────────────────────────────────────────────────────────────────────────────
   1. En Supabase, ve a SQL Editor
   2. Abre el archivo: database/database-schema.sql
   3. Copia TODO el contenido
   4. Pégalo en SQL Editor y ejecuta (Run)
   5. Verifica que se crearon las tablas:
      ✓ usuarios
      ✓ tickets
      ✓ ramplas
      ✓ muelles
      ✓ registros_tiempo
      ✓ notificaciones

2.4. Habilitar Realtime
─────────────────────────────────────────────────────────────────────────────
   1. En Supabase, ve a Database → Replication
   2. Habilita Realtime para:
      ✓ tickets
      ✓ ramplas
      ✓ muelles

2.5. Configurar Row Level Security (RLS)
─────────────────────────────────────────────────────────────────────────────
   Ver README.md sección "Configurar Row Level Security"
   Ejecuta los comandos SQL para habilitar RLS en todas las tablas

════════════════════════════════════════════════════════════════════════════════
💻 PASO 4: INSTALAR Y EJECUTAR (10 minutos)
════════════════════════════════════════════════════════════════════════════════

En la terminal, en la carpeta del proyecto:

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm start

# La app estará en: http://localhost:4200

Si hay errores:
- Verifica que Node.js esté instalado (node --version)
- Verifica que las credenciales estén correctas
- Revisa la consola del navegador (F12) para errores


════════════════════════════════════════════════════════════════════════════════
👤 PASO 5: CREAR USUARIOS DE PRUEBA (10 minutos)
════════════════════════════════════════════════════════════════════════════════

El sistema necesita usuarios para funcionar.

5.1. Crear Usuario en Supabase Auth
─────────────────────────────────────────────────────────────────────────────
   1. En Supabase, ve a Authentication → Users
   2. Click en "Add User" → "Create new user"
   3. Email: admin@tuempresa.com
   4. Password: (usa una segura)
   5. Copia el UUID generado (lo necesitarás)

5.2. Agregar Usuario a la Tabla 'usuarios'
─────────────────────────────────────────────────────────────────────────────
   En SQL Editor de Supabase:

   INSERT INTO usuarios (id, email, rol, nombre)
   VALUES 
     ('UUID-COPIADO-DEL-PASO-ANTERIOR', 
      'admin@tuempresa.com', 
      'admin', 
      'Administrador Sistema');

5.3. Crear Más Usuarios (Opcional)
─────────────────────────────────────────────────────────────────────────────
   Repite los pasos 5.1 y 5.2 para crear usuarios de cada rol:
   
   • admin → Acceso total
   • cd → Centro de distribución
   • planta → Operador de planta (agregar nombre_planta)
   • galpon → Operador de galpón


════════════════════════════════════════════════════════════════════════════════
🚚 PASO 6: CREAR RAMPLAS Y MUELLES (5 minutos)
════════════════════════════════════════════════════════════════════════════════

En SQL Editor de Supabase:

-- Ramplas de ejemplo
INSERT INTO ramplas (nombre, tipo_rampla, estado, activo)
VALUES 
    ('R-001', 'frugon_cerrado', 'Libre', true),
    ('R-002', 'frugon_cerrado', 'Libre', true),
    ('R-003', 'cortina', 'Libre', true);

-- Muelles de ejemplo
INSERT INTO muelles (nombre, estado, activo)
VALUES 
    ('Muelle A1', 'Libre', true),
    ('Muelle A2', 'Libre', true),
    ('Muelle B1', 'Libre', true);

Ajusta los nombres según tu inventario real.

📱 OPCIONAL: MICROSOFT TEAMS (Solo si tu empresa lo usa)

🚀 DESPLIEGUE A PRODUCCIÓN (Vercel - Recomendado)
════════════════════════════════════════════════════════════════════════════════

Cuando todo funcione en local:

1. Instala Vercel CLI:
   npm install -g vercel

2. Inicia sesión:
   vercel login

3. Despliega:
   vercel --prod

4. Configura variables de entorno en Vercel:
   Settings → Environment Variables → Add:
   - SUPABASE_URL = tu_url
   - SUPABASE_KEY = tu_key
   - TEAMS_WEBHOOK_URL = tu_webhook (opcional)

Ver README.md sección "Despliegue en Vercel" para más detalles.
